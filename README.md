# GardenCenter

Учебный курсовой проект — информационная система для садового центра.

Система предназначена для ведения каталога товаров (саженцев, удобрений, инвентаря), 
поиска товаров, оформления заказов клиентами и разграничения прав доступа для сотрудников.

## Возможности

- Просмотр каталога товаров с фотографиями, поиск по названию.
- Выбор текущего пользователя (демонстрация ролей).
- Оформление заказа с сохранением в базу данных.
- Автоматическая проверка прав доступа (Гость не может купить товар).
- Отображение заглушки, если у товара нет фотографии.

## Роли пользователей

- **Клиент** — просмотр каталога, поиск, оформление заказа на себя.
- **Менеджер** — просмотр каталога, поиск, оформление заказа на любого клиента.
- **Администратор** — все возможности менеджера, а также управление справочниками (в перспективе).

## Используемые технологии

- C# и .NET 10;
- Avalonia UI 11.0.10;
- Entity Framework Core 8.0.0 (подход Database First);
- Microsoft SQL Server;
- SQL Server Management Studio.

## Состав проекта

- `GardenCenter.Desktop` — исходный код приложения (папки Data, Models, Services).
- `database/garden_center.sql` — скрипт базы данных.
- `docs` — пояснительная записка.
- `resources` — сведения об источниках графических ресурсов.

## Подготовка базы данных

1. Откройте SQL Server Management Studio и подключитесь к своему экземпляру SQL Server.
2. Создайте пустую базу данных `garden_center`.
3. Откройте скрипт `database/garden_center.sql`.
4. Выполните скрипт для создания таблиц (roles, users, categories, products, product_variants, orders, order_items) и заполнения тестовыми данными.

## Настройка подключения

В папке проекта (рядом с `.csproj`) должен находиться файл `connection.txt`.
Укажите в нём строку подключения к вашей базе.

Пример для локального SQL Server с проверкой подлинности Windows:

```text
Server=DESKTOP-K64LUIR;Database=garden_center;Trusted_Connection=True;TrustServerCertificate=True;
